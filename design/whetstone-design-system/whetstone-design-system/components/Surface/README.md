# Surface

The page ground: `void` with film grain beneath and a vignette that darkens the corners, padded `space-6` (desktop) or `space-4` (phone).

- Wrap each page in exactly one Surface; never nest them or put one inside a Panel.
- `grain={false}` or `vignette={false}` to switch a texture off (e.g. in print or screenshots).

Consumer provides: `children`, optionally `as`, `grain`, `vignette`, `style`.
