# Divider

Thin hard rules that separate content: **plain** (1px `line`), **heavy** (double rule, iron over line, to close a section) and **ornament** (a centred pewter lozenge, or a `label` such as "Week XVII").

- Plain inside panels between entry and footer; heavy between major page sections; ornament at most once per screen, between weeks or epochs in the Chronicle.
- Never use a divider as a decorative border around content.

Consumer provides: `variant`, `label` (ornament only).
