# Tag

A small hard-edged label in `micro` caps for status and counts: **neutral** (iron outline, ash text), **iron** (pewter outline on `grave`), **blood** (on `blood-deep`, for gains and missed days) and **bone** (solid, for the one settled state, "Judged").

- One or two words. Never as a button and never interactive.
- Blood for things the person earned or lost; bone at most once per panel.

Consumer provides: `tone`, `children`.
